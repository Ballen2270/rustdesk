# 图片顺序与动作

素材为用户提供的 25 张截图（1–24、26；无 25），含 25px Windows 标题栏。副本名（二重影/因缘绘/绿烟如梦/蹈海去…）、地图、NPC、对话选项文字每天轮换，一律不作固定匹配条件，只按布局锚点识别。

| 图片 | 识别依据 | 动作及后继 |
| --- | --- | --- |
| [1.png](screens/1.png) | 组队完毕的地图，顶栏"指引/活动/排行"在 | 点顶栏"活动"打开面板 |
| [2.png](screens/2.png) | 活动面板：头部"活动"+左栏"日常活动"，列表两列，"绿烟如梦-普通四/蹈海去-普通四"各带同行"参加" | 先点"日常活动"页签；找含 `-普通` 的行点同行同列"参加"；不在视野先上后下有界滚动；完成条目的按钮已变灰会被跳过 |
| [3.png](screens/3.png) | 长安城百晓仙子，右侧"请选择要做的事"，首项"选择副本" | 点"选择副本"打开副本面板 |
| [4.png](screens/4.png) | 副本面板（普通页签）："普通副本/侠士副本"页签+"每日00:00刷新"，卡片按钮行有"进入" | 目标是侠士→点"侠士副本"页签；目标是普通→点"普通副本"页签后点最左可用"进入" |
| [5.png](screens/5.png) | 副本面板（侠士页签）："每周一00:00刷新"，一个可用"进入" | 点"进入"排队进本 |

| [7.png](screens/7.png) | 队员侧准备弹窗（准备/拒绝） | 队员设备全帧 OCR：`准?/淮?` 读数 + 同行左侧"拒绝"配对即按钮（未准备/已准备 行不配对；615px 小窗误读 淮备/准留 仍可检出），新帧复核后拟人点击"准备" |

| [10.png](screens/10.png) | "请选择要做的事"对话框，唯一选项 | **几何点击**选项带进战斗（选项文字随剧情轮换——住手！/不行！/好重的杀气…——不作识别依据） |

主循环：`1 → 2 → 3 → 4/5 → [6 等待] → 8/9 → 10 → 11 →（三循环 12–18）→ 19 → 20 → 21 → 22 → 2 → …`。副本内地图识别靠左上角时辰坐标行（顶栏在副本里隐藏）；城镇帧靠顶栏"活动"，混淆时用放大二次识别纠回。计次只认"副本已完成"或回城宽限恢复，不数战斗场次。
