# 秘境降妖自动挑战

每个窗口对应一个账号的单人活动。runner 走完整流程：正常界面 → 活动按钮 → 活动面板（必要时拟人滚动找到"秘境降妖"行）→ 参加 → 东海湾"请选择要做的事"选秘境降妖 → 面板点"继续挑战" → 副本内逐关推进 → 通关后点"离开"，记 1 轮。战斗全程游戏自动，脚本只观察；所有点击与滚轮都经过拟人层（坐标随机偏移且不重复、随机延迟、分段滚轮）。

## 开始前

统一窗口清单、队长/账号选择和跨设备启动见 [统一启动](../STARTUP.md)。优先使用生成的目标配置；不含 `window_selection` 的旧配置仍按下述方式校准。不要为窗口位置、设备或轮数变化修改活动脚本。

**每次启动第一件事：重新截图核对客户端位置（无需询问，直接做）。** 窗口位置会变，绝不沿用上一次的配置矩形——先抓每台设备全屏，确认每个配置窗口矩形内确实是游戏客户端（顶栏 活动/排行 按钮可见），不符就重新校准再启动。runner 侧有同款机械守卫：首帧不是正常界面会停机并把全屏截图存为运行目录的 `misaligned-<device>.png`，用它重新校准。

设计、安装或校准不等于开始挑战。用户明确说开始/试跑后才运行 `--execute`。用户指定轮数时遵从；否则默认配置的 rounds（每日次数有限，先确认剩余次数）。

仓库：`/Users/ballen/codeWorkSpace/vscode/rustdesk`。解释器从仓库 `.mcp.json` 的 rustdesk.command 读取。先读 `_framework/` 的模块 docstring 了解引擎边界；本 skill 的事实源在 `mcp/skills/rustdesk-mijing/`。

用 RustDesk MCP 获取 pc1 当前截图与原生分辨率，按 `assets/mijing.example.json` 建配置：窗口内容矩形（不含标题栏）、原生分辨率、`activity_button` 归一化锚点框（顶栏"活动"按钮，固定 UI）、`activity_list_scroll`（活动列表滚动区域），并设置 `calibrated=true`。配置放本地运行目录，不提交。画面中固定的是活动按钮与各面板锚点；其余元素（NPC、聊天、角色）都视为动态噪声，识别不依赖它们。窗口尺寸可能轻微变化但≈4:3，全部使用归一化坐标。

## 运行约定

- 状态机是声明式 workflow 节点（`scripts/mijing.py` 的 build_workflow）：每个节点 = 某画面下的一步动作 + 期望的确认画面 + 超时。确认靠观察，绝不盲重试；输入超时可能已送达，暂停核对。
- 副本内通用推进：空闲超过 `advance_delay` 秒即点"第N关"关卡信息面板（自动寻路+开战）；弹出"请选择要做的事"菜单（进入战斗/观看录像）就点"进入战斗"。不按关卡号分支——18/24/25 关的菜单由观察驱动。
- 战斗无时限，持续观察；锚点只维持已确认的战斗，不发起动作、不计数。
- 战斗结束后关卡长时间不推进（`advance_stall`，默认 150 秒）→ 暂停该窗口，等待人工根据日志与前后截图核对（可能是战斗失败或掉线），绝不自动重试或补数。
- "请选择要做的事"有两处：东海湾入口（秘境降妖/东海湾蜃境/规则说明/蜃境图鉴）与副本内战斗菜单（进入战斗/观看录像），靠选项集消歧。
- 计轮语义：`cleared` → 点"离开" → 回到正常界面才计 1 轮。轮数达标后不再开始下一轮，也不为收尾多点击。
- 首次观察必须是"正常界面"，否则暂停——拒绝半路接管进行中的流程。
- 未知画面持续 20 秒记录 warning 并禁输入，继续本地观察；识别恢复自动接续。
- 鼠标输入串行；脚本锁仅约束本 skill 实例（每设备一把），拦不住外部工具。禁止另一个 agent/MCP 会话同时输入同一设备。
- 用户说停止：在运行目录创建 STOP 文件，确认 state.json status 变为 stopped/stopped-ish；必要时对本脚本 PID 发 SIGTERM，不杀 bridge。

运行期间读取 state.json / events.jsonl / timeline.jsonl 及时报告每窗口进度（轮数、当前关卡、状态来源）；可用 viewer 网页观察台（与剑会共用，`--viewer` 拉起，端口默认 8789）。识别未知、掉线、布局变化或耗时过长时检查 latest-*.png，必要时暂停。不要让模型自行承担每秒轮询。

## 验证与限制

离线验证（不连接设备）：`test_mijing.py`（状态机/拟人/校验单测）→ `replay_mijing.py --images $REPO/images`（9 张参考图 + 战斗图的状态回放）→ `mock_e2e_mijing.py`（剧本 mock 驱动完整 25 关流程 + viewer API，点击全解析、坐标无重复）。参考图在 `images/normal/`（本机私有，不入库）。

限制：首次实机先 `--rounds 1` 试跑；活动面板条目顺序、入口按钮文案、战斗识别都基于当前参考图，界面改版需重新校准；OCR 对艺术字偶尔失真，识别来源（bands/full_ocr_fallback/anchors）在 timeline 中可查。离线通过不等于实机稳定，连续可靠性以试跑为准。
